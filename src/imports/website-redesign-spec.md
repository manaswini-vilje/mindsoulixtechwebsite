Redesign the entire website with a clean white background instead of black.

Theme Requirements:
- Primary Background: White (#FFFFFF)
- Primary Text: Black (#111111)
- Accent Color: Red (#E10600 or modern vibrant red)
- Color usage ratio:
  - 60% White
  - 30% Black
  - 10% Red (for CTA buttons, highlights, hover effects, underline indicators)

Add a subtle Metallic UI effect:
- Use soft metallic gradients (silver, chrome, light steel tones) for cards, buttons, and UI highlights
- Very subtle brushed metal texture on hover (light only, not dark)
- Soft reflective light effects
- Thin metallic borders on cards (light grey/silver tone)
- Slight glossy effect on buttons
- Keep it elegant, not futuristic cyberpunk
- Maintain premium enterprise feel

Design Style:
- Clean, minimal, modern corporate look
- Neat spacing with proper padding and margins
- Elegant micro-animations
- Subtle hover effects
- Soft shadows (very light, not heavy)
- Smooth transitions (300ms ease-in-out)
- Professional enterprise feel
- Creative but not flashy
- Unique layout with asymmetrical sections
- Use grid-based alignment
- Strong whitespace usage
- Structured content hierarchy

Typography:
- Do NOT use oversized fonts
- Use balanced typography scale
- Headings: Medium weight, clean and sharp
- Body text: Smaller, readable, professional
- Maintain proper line height and spacing
- Modern sans-serif font (Inter, SF Pro, or similar)

Navbar Design Changes:
- White navbar background
- Black text
- Red underline animation for active/hover item
- Slight metallic underline glow on hover
- On hover over navbar options:
    - Show a small, compact dropdown (NOT full-width mega menu)
    - Dropdown must appear directly under the hovered option
    - Light soft shadow
    - Rounded corners (8px)
    - Clean white dropdown background
    - Thin metallic border
    - Smaller font size
    - Proper spacing between items
    - Subtle fade + slide down animation (200–300ms)

Dropdown Interaction:
- Each dropdown item must be clickable
- Clicking an item must navigate to its respective page
- Add subtle hover background highlight (very light grey or soft red tint)
- Add smooth hover transition

Buttons:
- Primary buttons: Red background
- On hover: Slightly darker red
- Add subtle metallic shine animation on hover
- Rounded corners (6–8px)
- No oversized button styles

Cards & Sections:
- White sections with soft metallic borders
- Light shadow depth (very subtle)
- Slight glass or chrome edge highlights
- Clean grid layout
- Maintain simplicity and clarity

Animation:
- Smooth page transition animation (fade or slide)
- Underline animation on navbar hover
- Micro-interactions on cards
- No excessive motion

Overall Goal:
Make the website look:
- Clean
- Neat
- Effective
- Creative
- Professional
- Enterprise-ready
- Modern SaaS style
- Premium white tech brand
- Subtle metallic elegance

Avoid:
- Large bulky dropdowns
- Oversized fonts
- Heavy black backgrounds
- Too many animations
- Cyberpunk look
- Cluttered layout
- Dark metallic theme (keep it light premium metallic)
